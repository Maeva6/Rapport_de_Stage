\chapter{Glossaire}
\label{annexe:glossaire}

\begin{description}
  \item[Proxmox VE] Plateforme de virtualisation open-source (VM et conteneurs LXC).
  \item[Docker / Docker Compose] Outils de conteneurisation et d'orchestration multi-conteneurs sur une même machine.
  \item[Traefik] Reverse proxy qui route le trafic HTTP(S) vers les conteneurs et gère les certificats TLS automatiquement.
  \item[Let's Encrypt] Autorité de certification gratuite délivrant des certificats TLS.
  \item[DuckDNS] Service de nom de domaine dynamique gratuit.
  \item[Jenkins] Serveur d'intégration et de déploiement continu (CI/CD).
  \item[UFW] Pare-feu simplifié pour Linux (surcouche à iptables).
  \item[Fail2ban] Service qui bannit temporairement les IP après des tentatives de connexion suspectes.
  \item[Webhook] Notification HTTP automatique envoyée par un service vers une URL à chaque événement.

\end{description}
