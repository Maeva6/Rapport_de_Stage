\chapter{Configuration excerpts}
\label{annexe:config}

Sensitive values (tokens, passwords, tunnel identifiers) are kept out of this report; every excerpt below is copied from the working configuration, with only such values removed.

\section{docker-compose.yml (dashboard port and Cloudflare Named Tunnel)}
\begin{lstlisting}
control-center:
  ports:
    # Published only on the LAN address: Docker bypasses UFW
    # for published ports (format IP:hostPort:containerPort).
    - "192.168.x.x:3000:3000"

cloudflared:
  image: cloudflare/cloudflared:latest
  container_name: devops-cloudflared
  restart: unless-stopped
  # --protocol http2: the default protocol (QUIC/UDP) drops
  # frequently on a satellite link (Starlink), whose NAT closes
  # idle UDP sessions; HTTP/2 (TCP) is more stable here.
  # user 1000:1000 lets the container read the credentials file (mode 600).
  user: "1000:1000"
  command: tunnel --no-autoupdate --protocol http2 --config /etc/cloudflared/config.yml run info-control-center
  volumes:
    - /home/<user>/.cloudflared/config.yml:/etc/cloudflared/config.yml:ro
    - /home/<user>/.cloudflared/credentials.json:/etc/cloudflared/credentials.json:ro
  depends_on:
    - control-center
  networks:
    - devops-net
\end{lstlisting}

  steps {

  steps {
    sh '''
      for i in 1 2 3 4 5 6; do
        if docker exec devops-control-center wget -qO- http://127.0.0.1:3000/health; then

        fi
        sleep 5
      done
      exit 1
    '''
  }
}

\section{SSH hardening (/etc/ssh/sshd\_config.d/00-hardening.conf)}
\begin{lstlisting}
PasswordAuthentication no
KbdInteractiveAuthentication no
PermitRootLogin no
\end{lstlisting}

The file name starts with \texttt{00} so that it is read before any other file of the folder, since the SSH daemon keeps the first value it reads for each option. The effective result is checked with \texttt{sudo sshd -T}.

\section{UFW rules (excerpt, after hardening)}
\begin{lstlisting}
[ 1] 22/tcp                     LIMIT IN    Anywhere              # SSH anti brute-force
[ 2] 80/tcp                     ALLOW IN    Anywhere              # HTTP
[ 3] 443/tcp                    ALLOW IN    Anywhere              # HTTPS
[ 4] 3000/tcp                   ALLOW IN    192.168.1.0/24        # Dashboard - LAN only
[ 5] 8000/tcp                   ALLOW IN    192.168.1.0/24        # Traefik dashboard - LAN only
[ 6] 8080/tcp                   ALLOW IN    192.168.1.0/24        # Traefik dashboard - LAN only
[ 7] 8081/tcp                   ALLOW IN    192.168.1.0/24        # Jenkins - LAN only
\end{lstlisting}

These rules do not cover ports that Docker publishes itself, which is why the dashboard port is also bound to the local network address in the Compose file (see chapter~\ref{chap:securisation}).
