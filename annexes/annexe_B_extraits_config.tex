\chapter{Configuration excerpts}
\label{annexe:config}

Sensitive values (tokens, passwords) are kept out of this report; every excerpt below is copied as-is from the working configuration, with only such values removed.

\section{docker-compose.yml (Cloudflare Tunnel service)}
\begin{lstlisting}
cloudflared:
  image: cloudflare/cloudflared:latest
  container_name: devops-cloudflared
  restart: unless-stopped
  # --protocol http2: the default protocol (QUIC/UDP) drops
  # frequently on a satellite link (Starlink), whose NAT closes
  # idle UDP sessions -- HTTP/2 (TCP) is more stable here.
  command: tunnel --no-autoupdate --protocol http2 --url http://control-center:3000
  depends_on:
    - control-center
  networks:
    - devops-net
\end{lstlisting}
